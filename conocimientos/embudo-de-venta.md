# Embudo de venta (cómo se convierte una paciente)

1. **Interés en redes** → sí hay interés.
2. **Mercadotecnia contesta los mensajes** → aquí se pierde: Isela percibe falta de interés y de seguimiento.
3. **Contact center cierra la consulta** (por WhatsApp; con prepago hay un pequeño descuento) → aquí también falta seguimiento.
4. **Consulta con el médico** → **la venta la hace el médico** con base en la consulta (diagnóstico: composición corporal, examen facial digital, tricoscopía).
