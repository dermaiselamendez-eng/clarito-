# Claude Code Clarity

Carpeta de trabajo para llevar tu negocio con Claude Code: memoria del negocio, personalidad del asistente, protocolos, habilidades, mapa y laboratorio de actividades. Claude la lee al empezar cada conversación (ver `CLAUDE.md`).

## Instalar

1. Descarga este proyecto como ZIP (botón verde **Code** → **Download ZIP**) y descomprímelo.
2. Entra a `instalador/` y da doble clic en:
   - **Mac:** `Instalar en Mac.command`
   - **Windows:** `Instalar en Windows.bat`
3. Al final verás **✔ Listo** o **✖ Se atoró en…** con lo que hay que hacer.

El instalador pone las herramientas (git, Node, FFmpeg, uv, Python), las apps (Claude, Obsidian, Chrome y dictado), Claude Code, Playwright y Graphify, y copia esta carpeta a `Documentos/Claude Code Clarity` sin sobrescribir nada. Se puede repetir sin problema. Detalles en [`instalador/LEEME.md`](instalador/LEEME.md).

## Privacidad

Los datos de clientes (`clientes/`), capturas, videos y archivos `.env` nunca se suben al repositorio.
